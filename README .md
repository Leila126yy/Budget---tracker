# Budget Tracker - SpendWise Dashboard

## About the Project

SpendWise is a modern personal finance dashboard shell created as the foundation for a budget tracking application.

The dashboard displays realistic static financial information for different spending categories.

## Features

- Sidebar navigation
- Dashboard header
- Six financial category cards
- Food spending
- Transport spending
- Rent
- Entertainment
- Savings
- Utilities
- Spending progress bars
- Responsive mobile layout
- Hover effects on dashboard cards
- Keyboard focus effects
- Dark theme support

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Custom Properties
- CSS Media Queries
